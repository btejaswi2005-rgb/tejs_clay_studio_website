Tej's Clay Studio — Freelance Client Website
Built a complete single-page portfolio website for a handmade clay charm business based in Vijayawada. The client needed a clean way to showcase their products online and let customers reach out to order directly.
The site includes a product catalog with category filtering (keychains, fridge magnets, letter customisation, gifts, bag pins, bookmarks), an order flow that pre-fills a WhatsApp or Instagram DM with the item details, and a custom commissions button for personalized orders.
Built with plain HTML, CSS, and vanilla JavaScript — no frameworks. Deployed on Netlify.
